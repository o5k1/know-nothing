# Learning resources

Each step comes with 1–3 optional picks so the user can go deeper if they want. They're extras, never a reading list to finish before the challenge.

## Picking good ones

- **Prefer official docs and well-known sources:** the language or tool's own documentation, respected teachers and channels, university or well-known community material. They're most likely to be accurate and stay online.
- **Mix formats** across a step: one video and one page work better than three articles. Add something hands-on when it fits (an interactive playground, a sandbox, a kata).
- **Match the user's level** from the opening conversation. A beginner needs a gentle intro, not the reference spec. An expert needs the spec, not the intro.
- **Be specific:** a section, a chapter, a timestamp range. "The 'Ownership' chapter" beats "the Rust book".
- **Fit the step:** each pick should help with *this* challenge. If you can't say why in one line, drop it.
- **Non-coding goals:** same rules. Use the equivalent: a well-known teacher's channel, a reputable site for the craft, an interactive tool.

## Checking links

**Never make up a URL.** A wrong link costs the user's trust and time.
- With WebSearch or WebFetch available: search, then open the page and check it exists and covers what you claim, before offering it.
- Without them: don't give a URL. Give a precise search query the user can paste in: "YouTube: fireship rust ownership in 100 seconds" or "MDN: Array.prototype.map".
- Say which it is when relevant: a verified link, or a search query.
- If you're unsure a video is still available, or whether it's current, prefer a doc page or a query.

## Label format

One line each, with a type icon, size and why it helps:

- 📺 video · 12 min: shows the memory model drawn live, which makes the diagram click
- 📄 official docs · the "Ownership" section: short and exact, good to keep open while you work
- 📝 article · 5 min read: walks through the same mistake you just made
- 🧪 interactive · 10 min: practise it right in the browser, no setup

Keep it to 1–3 lines. More than that stops being a hint and turns into homework.

## Where they go

- Present them right after the challenge is framed, as "if you'd like a hand, these might help".
- Save them in the step's section of `.know-nothing/journey.md` so they can be found again.
- When a gap keeps coming back, point at the pick that covers it (rung 2 of the hint ladder).
- After a cleared step, one "go deeper" pick can go with the stretch idea.
- In the wrap-up, each "next quest" gets a starting resource.
